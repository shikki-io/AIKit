# AIKitPublicAPI.txt — every public symbol AIKit and AIKitMLX export.
#
# W27 of spec ai-layer-aikit-core-2026-10-31, BR-AIL-21, operator 2026-11-12:
# "making all the ai providers api private to the AIKit ... the public api
# surface of the AIKit package should be thin with one system to talk to ai
# providers, one list of providers type we managed and the hugging face
# endpoint to go to grab some provider to dl them".
#
# WHAT THIS FILE IS FOR. Adding a `public` keyword is a decision about what
# this package promises for a major version, and it used to be invisible: 130
# public types accumulated, and shikki's epic reached 55 of them — mostly
# internals (AIWireStandard x29, OpenAIProvider x19, LMStudioProvider x12).
# Nothing said no. Now a new `public` fails `PublicSurfaceTests` until its line
# is added HERE, so it arrives in review as an edit to an allowlist and not as
# a diff hunk nobody read.
#
# HOW TO REGENERATE the symbol lines:
#
#     scripts/public-api.sh --write
#
# That is the SAME script `PublicSurfaceTests` runs (BR-EC-02: one code path,
# so the file cannot be written by one rule and checked by another). Lines
# starting with `#` are review notes; the test ignores them and `--write`
# keeps them.
#
# -----------------------------------------------------------------------------
# THE FOUR DOORS (BR-AIL-21). Everything public below belongs to one of them.
#
# 1. SETTINGS IN — which providers exist, where, and with which model.
#    AIProviderSettings, AIProviderEntry, AIProviderOptions,
#    AICLISubprocessOptions, AIProviderFamily (the one list of provider types),
#    AIProviderID, AIServerAddress, AIProviderRepository, AIProviderFactory,
#    AIProviderSet, AIKitAssembly, RuntimeEngine, HostPlatform.
#
# 2. TALK — one entry point, and orchestration over it (BR-AIL-15, BR-AIL-22).
#    AIProvider, AIRequest, AIMessage, AIInput, AIMediaKind, AIMediaSource,
#    ResponseFormat, AIResponse, AIOutput, AIChunk, TokenUsage, AICapabilities,
#    AIProviderStatus, AIKitError, AIProviderAttempt, AIRequestTarget,
#    FallbackEligibility, ProviderRouter, ProviderPreferences, PerformanceStore,
#    PerformanceStat, UsageContext.
#
#    W32 (BR-AIL-22) added ORCHESTRATION over that one entry point, and it
#    belongs to this door rather than a fifth one: a caller already holds
#    `any AIProvider` and calls `complete`, and choosing WHICH providers and
#    asking several at once is the same conversation, not a different kit.
#    Operator 2026-11-12: *"shikki gonna have the possibility to target every ai
#    providers to orchestrate with the public api … in function of the topics and
#    the capabilities of the current device … dispatch on different ai provider
#    in //"*. Each symbol, with why it is public rather than internal:
#      * ProviderRouter.candidates(for:policy:providers:) — the selection, as a
#        value a caller can render. Internal would mean every consumer rebuilds
#        the capability + device + topic filter, which is the duplication this
#        whole spec removes.
#      * ProviderRouter.fanOut(_:to:deadline:) and (_:to:within:) — the parallel
#        ask. Two forms because a shared deadline IS an instant and a caller's
#        budget is a duration; converting at the boundary beats re-deriving it
#        per branch.
#      * AIRoutingPolicy — what the caller wants routed where, built from data
#        so the topic vocabulary stays in shikki (BR-AIL-03, BR-AIL-04) and
#        AIKit never learns what a stage name means.
#      * AILocalModelPlacement — which providers are LOCAL and what each would
#        load, because `AIProvider` deliberately says neither. Also the cluster
#        case: one entry, one pooled-memory figure, no new family.
#      * AIRoutingPlan / AIProviderRejection / AIRoutingRejection — the
#        selection AND the reasons. BR-AIL-22 requires that nothing be silently
#        skipped, and a reason a caller cannot read is a silent skip: these must
#        leave the router or the rejections could only be logged inside it.
#      * AIProviderOutcome and its Verdict — one answer-or-failure per branch,
#        each naming its provider, model and latency (BR-AIL-06, BR-AIL-07). A
#        fan-out has no single answer, so it cannot return `AIResponse`;
#        `.attempt` bridges a failed branch back to `AIProviderAttempt` so a
#        caller reports "nobody answered" with the kit's existing error.
#
# 3. GET MODELS — the catalogue, the store, and what this device can load.
#    ModelRegistry, DefaultModelRegistry, ModelFilter, ModelDescriptor,
#    ModelIdentifier, ModelDomain, ModelFormat, ModelStore, ModelFile,
#    ModelFileDigest, ModelFileDestination, ModelStoreError,
#    ModelVerificationReceipt, ModelRepositoryDirectory, ModelRepositoryFile,
#    ExternalModelLibrary, LocalModelStore, LocalModel, LocalModelFile,
#    LocalModelManifest, LocalModelDirectory, LocalModelStoreError,
#    AIKitNode, AIKitPaths, DeviceCapability, DeviceClass, DeviceRow,
#    DeviceRowProvenance.
#    The Hugging Face endpoint is NOT here: HuggingFaceClient,
#    HuggingFaceEndPoint and ModelDownloader are internal, reached through
#    ModelStore.publishedFiles / .fetchPublishedFile and DefaultModelRegistry.
#
#    W33 (BR-AIL-23) added the PLAN a download is made under, and it belongs to
#    this door for the reason the store does: a caller choosing a model has to
#    be able to say "needs 4.1 GB, 2.3 GB free" and "this is cellular" BEFORE
#    anything starts, and a refusal it cannot read is a refusal it cannot
#    render. Each symbol, with why it is public rather than internal:
#      * ModelDownloadPlan — the value an interface renders: bytes to fetch
#        (verified files subtracted), bytes free, the margin, the network path.
#        Internal would mean the UI recomputes it, which is two answers.
#      * ModelDownloadDecision / ModelDownloadRefusal /
#        ModelDownloadConsentReason — the three outcomes, as cases carrying
#        their numbers, so nothing is parsed back out of a sentence.
#      * ModelDownloadNetwork — what was observed, kept distinct from what was
#        concluded, including `.unknown` for a platform with no `Network`.
#      * ModelDownloadSettings — the `[models.download]` table of the host's
#        own settings document; a host reads it and hands it over, exactly as
#        it does the provider list (door 1's rule, BR-AIL-20).
#      * ModelDownloadConsent — the per-download answer, which only a caller
#        can obtain.
#      * ModelDownloadPlanner — where the two measurements are made. Public
#        because the host injects the policy; its probes are injectable for the
#        same reason every seam in this kit is.
#      * AIKitError.insufficientSpace / .downloadNeedsConsent — door 2 already
#        exports AIKitError; these are its two new cases.
#
#    W28 (shikki onto the four doors) made the Claude model identity public
#    again, in this door because it names models a caller can ask for:
#      * ProviderModelCatalog (+ `default`, `canonical(for:)`, `resolve(_:)`,
#        `allCanonicalIds`, `merging(operatorAliases:)`), AnthropicFamily —
#        the ONE place a canonical Claude id and its aliases (`opus`,
#        `claude-sonnet`, …) are spelled. AIKit itself needs it for the CLI
#        family's model aliases; shikki needs the same ids for its cost table
#        and its category router. Internal would force shikki to copy the
#        table, i.e. a second source of truth that drifts on the next model.
#      * HistoricalAnthropicId — frozen ids kept for cost telemetry, read by
#        shikki's cost catalog.
#      * ProviderModelCapability — the prefix tiers shikki's cost router
#        matches models against; same reason, one list.
#
# 4. TOOLS AND CAPABILITIES — what a provider may call, and what a device can do.
#    AITool, AIToolCall, AICapabilities, MLXVideoPreset, VideoResolution,
#    VideoFrameRate, VideoPresetRefusal.
#
# AIKitMLX exports its family registration and nothing else: AIKitMLX.family
# and AIKitMLX.register(into:store:device:). MLXInProcessProvider,
# MLXContainerSession, MLXHubDownloader, MLXModelSession, MLXSessionLoader,
# MLXProviderError and TransformersTokenizerLoader are all internal now.
#
# The test doubles are not in either product: MockAIProvider,
# MockModelRegistry and MockRuntimeEngine live in AIKitTestSupport
# (W26, r4500328752), which MockProductBoundaryTests pins.
#
# -----------------------------------------------------------------------------
# PUBLIC WITHOUT BEING A DOOR — each one named, with its reason and its move
# (BR-AIL-21 item 2: "Never keep one silently").
#
# ClaudeSessionIndex, ClaudeSessionIndexProvider, AgentSessionIndexProvider,
# AgentSessionEntry, BudgetLedger — not AI communication: a session index reads
#   the operator's `~/.claude/projects/**/*.jsonl`, a budget ledger accounts
#   spend per provider id. Both are host bookkeeping about an agent run and
#   belong to shikki. Kept public because internalising them breaks shikki with
#   nothing in AIKit to replace them, and the move is a cross-repo change with
#   an AIKit major in the middle — not a wave that touches AIKit only.
#   MOVE: backlog 93b6b6f9-9fc1-48df-a521-ae1ddfd5a5a1.
#
# MediaLanguagePreferences, MediaProfile, MediaType, SourceBehavior,
# MediaLanguageResolver, TranslationDecision — a caller's content policy (which
#   language to want a media asset in, and whether to translate), which AIKit
#   then carries as `systemPrompt` and `messages` like any other caller
#   decision (BR-AIL-03). Measured at W27: inside AIKit they are referenced
#   only by each other, so internalising them would leave six unreachable types
#   in the kit AND break whichever consumer reads them.
#   MOVE: backlog 7ae659cc-3856-4902-9c13-75efa974e250.
#
# -----------------------------------------------------------------------------
# One line per symbol: <module>  <kind>  <dotted path>. A rendering two symbols
# share — a protocol requirement and its default implementation, or two
# overloads — carries its mangled USR in brackets, the only thing that always
# tells them apart.
